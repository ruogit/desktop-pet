# Jili Desktop Pet

![Jili Tiger](screenshot.png)

A cute tiger desktop pet application built with Python + PyQt5. Jili is an adorable tiger character with a big head and small body, very cute! It will walk, idle, and interact with you on your desktop, providing practical features like timed eye care reminders.

## Features

### 📝 Core Features
- **Transparent frameless window**: Jili displays on your desktop with a transparent background, always on top
- **Drag and drop interaction**: Drag Jili to any position on the screen with your mouse
- **State system**: Includes idle, walking, sleeping, eating, waving, and other states
- **Click interaction**: Single click to jump, double click to wave/heart
- **Right-click menu**: Complete context menu with various interaction options

### 🎨 Character Design - Cute Tiger
- **Big head, small body**: Head is significantly larger than body for a cute Q-style proportion
- **Rounded shapes**: All parts use circular design to enhance cuteness
- **Tiger features**: Round big ears, brown stripes, pink nose, whiskers
- **Cute expression**: Big round eyes with highlights, pink blush, small mouth
- **Color scheme**: Orange (#FFB366) + White (#FFF5E6) + Brown stripes (#8B4513) + Pink accents

### ⏰ Reminder System
- **Eye care reminder**: Default every 45 minutes to protect your vision
- **Water reminder**: Default every 30 minutes to stay hydrated
- **Activity reminder**: Default every 60 minutes to promote health
- **Customizable settings**: Adjust reminder intervals and toggle status
- **Random messages**: Each reminder shows different warm messages

### 💬 Random Interaction
- **Chat bubbles**: Randomly pops up cute dialogue bubbles
- **Affection system**: Increase affection through interaction, affects behavior
- **Special behaviors**: More frequent interaction at high affection, tantrums at low affection

### 🖥️ System Integration
- **System tray**: Minimize to system tray, doesn't take up taskbar space
- **Configuration save**: All settings automatically saved, retained after restart
- **Lightweight**: No external image dependencies, all graphics generated by code

## Running

### Start Application
Run in the project directory:
```bash
python main.py
```

### First Run
- Jili will appear at the bottom right of the screen
- Default position is bottom right corner
- Will enter idle state after startup

### Exit Application
- Right-click Jili and select "Exit"
- Or select "Exit" from the system tray icon right-click menu

## Features

### State System
Jili has the following states, which switch automatically:

| State | Description | Trigger |
|-------|-------------|---------|
| IDLE | Idle state, body sways slightly, stars twinkle | Default state |
| WALKING | Walking state, moves left and right at bottom of screen | Auto switch |
| DRAGGING | Being dragged, surprised expression | Mouse drag |
| FALLING | Falling state, limbs spread | Drag release |
| SLEEPING | Sleeping state, eyes closed, Zzz bubbles | Long inactivity |
| EATING | Eating state, mouth opens and closes | Right-click "Feed Pudding" |
| WAVING | Waving state, one hand waves | Right-click "Wave" |
| REMINDING | Reminder state, hands raised above head | Timed reminder trigger |

### Interaction Methods

#### Mouse Operations
- **Single click**: Jili jumps, stars twinkle above head
- **Double click**: Randomly makes a heart or waves
- **Drag**: Hold left button to drag Jili to any position
- **Right-click**: Open context menu

#### Right-click Menu
- **Feed Pudding**: Switch to eating state, increase affection
- **Sleep / Wake**: Toggle sleep state
- **Wave**: Switch to waving state
- **Reminder Settings**: Open reminder settings dialog
- **About Jili**: Show about information
- **Exit**: Exit program

### Reminder Features

#### Reminder Types
1. **Eye Care Reminder** (default 45 minutes)
   - Reminds you to look at something far away, let your eyes rest
   - Includes 20-20-20 eye care rule suggestions

2. **Water Reminder** (default 30 minutes)
   - Reminds you to stay hydrated, 8 cups a day
   - Cute encouraging messages

3. **Activity Reminder** (default 60 minutes)
   - Reminds you to get up and stretch
   - Promotes healthy work habits

#### Reminder Settings
Through right-click menu → "Reminder Settings" you can:
- Toggle each reminder
- Customize reminder intervals (minutes)
- Settings are automatically saved

#### Reminder Behavior
- When reminding, Jili switches to REMINDING state
- Large bubble appears above head showing reminder content
- Bubble has close button in top right
- Bubble has confirm button at bottom
- After clicking confirm, Jili happily jumps
- If no response within 5 minutes, secondary reminder triggers
- Multiple reminders queue for display, 30 second interval

### Affection System

#### Increase Affection
- Click interaction: +2
- Respond to eye care reminder: +3
- Feed pudding: +5

#### Decrease Affection
- Ignore reminder (no response for 5 minutes): -1

#### Affection Effects
- **High affection (>80)**: More frequent random chat, heart effects appear
- **Low affection (<30)**: Jili turns away, needs clicking to coax back

### System Tray
- Shows Jili icon
- Tooltip shows time until next reminder
- Right-click menu:
  - Show/Hide Jili
  - Toggle each reminder
  - Exit program

## Configuration File

### Configuration File Location
Configuration file saved in user home directory:
```
~/.jili_config.json
```

### Configuration File Format
```json
{
  "reminders": {
    "eye_enabled": true,
    "water_enabled": true,
    "activity_enabled": true,
    "eye_interval": 45,
    "water_interval": 30,
    "activity_interval": 60
  },
  "affection": 50
}
```

### Configuration Items
- `eye_enabled`: Eye care reminder toggle
- `water_enabled`: Water reminder toggle
- `activity_enabled`: Activity reminder toggle
- `eye_interval`: Eye care reminder interval (minutes)
- `water_interval`: Water reminder interval (minutes)
- `activity_interval`: Activity reminder interval (minutes)
- `affection`: Affection score (0-100)

## Animation Effects

### IDLE (Idle)
- Body slightly floats up and down (2px)
- Stars twinkle alternately above head
- Occasional blinking

### WALKING (Walking)
- Left and right feet alternate stepping
- Body sways slightly left and right
- Small arms swing naturally

### DRAGGING (Being Dragged)
- Expression becomes surprised (mouth becomes O shape)
- Eyes enlarge
- Limbs slightly spread

### FALLING (Falling)
- Limbs fully spread
- Body maintains falling posture
- Has gravity acceleration effect

### SLEEPING (Sleeping)
- Both eyes closed
- Body still
- "Zzz" bubbles gradually float up and disappear

### EATING (Eating)
- Mouth opens and closes animation
- Small hearts pop up beside
- Happy expression

### WAVING (Waving)
- Right hand waves up and down
- Body slightly turns toward waving direction
- Text bubble appears above head

### REMINDING (Reminding)
- Both hands raised above head swaying left and right
- Serious expression
- Attention-grabbing posture

## Troubleshooting

### Common Issues

**Q: Can't see Jili after program starts?**
A: Check if other windows are blocking, Jili defaults to bottom right. Can show/hide via system tray icon.

**Q: Reminders not working?**
A: Check if reminder settings are enabled, confirm via right-click menu → "Reminder Settings".

**Q: Configuration not saved?**
A: Ensure program has write permission to user home directory, check `~/.jili_config.json` file.

**Q: Animation lagging?**
A: Check system resource usage, close other GPU-intensive programs.

**Q: How to reset all settings?**
A: Delete `~/.jili_config.json` file, program will use default settings.
